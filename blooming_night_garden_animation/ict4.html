    ข้อมูลทั่วไป
    รายการตรวจสอบครุภัณฑ์ ทะเบียนคุมทรัพย์สิน เวรรักษาการณ์
    E – Reports
    การปฏิบัติงานรายไตรมาส (รต.1-8) การประชุมผ่านระบบวิดีทัศน์ทางไกล (VCS) การปฏิบัติงานระบบสื่อสารผ่านดาวเทียม (TDMA) การรับ-ส่งข่าว แผนปฏิบัติการดิจิทัลศูนย์ฯ สถิติการใช้กระแสไฟฟ้า
    สรุปผลการดำเนินงาน
    การจัดทำรายงานประจำปี สรุปผลการประเมินการปฏิบัติราชการ (ITA)
    ข้อมูลด้านช่าง
    วงจรเช่าทางไกลในเขต ศสข.4(นม) ผู้ขอใช้บริการเครือข่าย Online ข้อมูลทางด้านเทคนิค (สื่อสารข้อมูลและ ATM) Access Code เครือข่ายโทรศัพท์ มท. จำนวนหมายเลขในเขตรับผิดชอบ สถานที่ติดตั้งโทรศัพท์ มท.
  • คำสั่ง / ระเบียบ▾
    คำสั่ง
    คำสั่งแบ่งงานและมอบหมายหน้าที่ คำสั่งตรวจเวรสถานที่ราชการ คำสั่งมอบอำนาจการบริหารงานพัสดุ คำสั่งบริหารจัดการบ้านพัก คำสั่งประเมินผลการทดลองปฏิบัติหน้าที่ฯ คำสั่งมอบอำนาจการเดินทางไปราชการ
    ระเบียบ / ข้อบังคับ
    ระเบียบการเข้าอยู่บ้านพักของราชการ ข้อบังคับเงินออมสวัสดิการของ ศสข.4 หลักเกณฑ์การใช้รถยนต์ส่วนกลาง ระเบียบว่าด้วยเงินทดรองราชการ
  • คู่มือ / ดาวน์โหลด▾
    คู่มือระบบงานและซอฟต์แวร์
    ระบบสารบรรณอิเล็กทรอนิกส์ (e-Document) ระบบ E-office ของ ศสข.4 การใช้งาน C-MOI Webmail การใช้งาน Jabber (PC/Mobile) ระบบการจัดเก็บข้อมูล Log File โปรแกรม AnyDesk
    คู่มือเครือข่ายและฮาร์ดแวร์
    MOI Network Management ระบบรักษาความปลอดภัยสารสนเทศ การดูแลรักษาระบบเครือข่าย (Troubleshooting) การใช้เครื่องโทรศัพท์ IP Phone ระบบ Video Conference / Webex Meeting การบำรุงรักษาระบบไฟฟ้าสำรอง (UPS) การแชร์ File และ Printer ในระบบ Network แนวทางการแก้ไขปัญหา Printer
    ดาวน์โหลดแบบฟอร์ม
    แบบฟอร์ม Front Office / Back Office แบบฟอร์มขออนุญาตลางาน/ลาป่วย/ลาพักผ่อน แบบฟอร์มสรุปรายงานการปฏิบัติหน้าที่ รปภ. แบบฟอร์มขอรับความช่วยเหลือด้าน IT แบบฟอร์มคำชี้แจงตัวชี้วัด (IPA3)

ศูนย์เทคโนโลยีสารสนเทศและการสื่อสาร เขต 4 (นครราชสีมา) เป็นหน่วยงานในสังกัดสำนักงานปลัดกระทรวงมหาดไทย มีภารกิจหลักในการวางระบบเครือข่ายสื่อสาร สนับสนุนการประชุมทางไกล และดูแลความมั่นคงปลอดภัยด้านสารสนเทศให้แก่หน่วยงานราชการในเขตพื้นที่รับผิดชอบ

ครอบคลุมพื้นที่ 5 จังหวัดภาคอีสานตอนล่าง ได้แก่ นครราชสีมา บุรีรัมย์ สุรินทร์ ศรีสะเกษ และอุบลราชธานี ทำหน้าที่เชื่อมโยงการสื่อสารของภาครัฐให้รวดเร็ว มั่นคง และเข้าถึงประชาชนได้อย่างทั่วถึง
