    รายงานสรุปผลการดำเนินงาน
    การปฏิบัติงานรายไตรมาส (รต.1-8) การประชุมผ่านระบบวีดิทัศน์ทางไกล (VCS) การปฏิบัติงานระบบสื่อสารผ่านดาวเทียม (FTDMA) รายการตรวจสอบครุภัณฑ์ การจัดทำรายงานประจำปี เวรรักษาการณ์สถานที่ราชการ การรับ-ส่งข่าว สถิติการใช้กระแสไฟฟ้า
    ข้อมูลด้านเทคนิคและเครือข่าย
    วงจรเช่าทางไกลในข่าย ศสข.4 (นม) ผู้ขอใช้บริการเครือข่าย Online สถานที่ติดตั้งโทรศัพท์ มท. ในจังหวัดนครราชสีมา จำนวนเลขหมายโทรศัพท์ในเขตรับผิดชอบ Access Code เครือข่ายโทรศัพท์ มท.
